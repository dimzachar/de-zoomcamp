# NYC Taxi Pipeline with Bruin

This project recreates the NYC Taxi data pipeline from Module 04 (dbt/Analytics Engineering) using Bruin.

We're building the same layered architecture:
- Ingestion layer: Load raw taxi trip data
- Staging layer: Clean and transform the data
- Reports layer: Create analytics-ready aggregations

The goal is to replicate what we did with dbt, but using Bruin's unified platform for data ingestion, transformation, and orchestration.
